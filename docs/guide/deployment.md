# Deployment

## Overview

**slaty.dev** is hosted on [Laravel Forge](https://forge.laravel.com) and auto-deploys from the `main` branch.

## Branch Strategy

| Branch | Purpose |
|--------|---------|
| `main` | Production — auto-deploys to slaty.dev via Forge |
| `topic/improvements` | Active development branch |

**Never push directly to `main`.** All work happens on `topic/improvements` (or a feature branch), then merges to `main` when ready.

## Deploy Flow

1. Work on `topic/improvements`
2. Run `php artisan test` — all green
3. Run `npm run build` — clean build
4. Merge to `main`
5. Forge detects the push and auto-deploys

## Forge Deploy Script

The Forge deploy script (configured in the Forge dashboard) runs approximately:

```bash
cd /home/forge/slaty.dev
git pull origin main
composer install --no-interaction --prefer-dist --optimize-autoloader
npm ci && npm run build
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

## Environment Variables

Key variables in `.env` / Forge environment:

| Variable | Description |
|----------|-------------|
| `APP_NAME` | Application name |
| `APP_ENV` | `production` on Forge |
| `APP_URL` | `https://slaty.dev` |
| `APP_KEY` | Generated by `php artisan key:generate` |

No database credentials needed — the portfolio has no database-backed features.

## Validation Checklist Before Merging

- [ ] `php artisan test` — all pass
- [ ] `npm run build` — no errors
- [ ] Visual check at `localhost:8000`
- [ ] Lighthouse score 95+ (run from Chrome DevTools or PageSpeed Insights)
